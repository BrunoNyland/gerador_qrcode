# Gerador de QR Code

Este é um projeto moderno e interativo para a criação de QR Codes, desenvolvido com Angular.

## 🚀 Demo Online

O projeto está no ar e pode ser utilizado diretamente através do link:
👉 **[qrcode.brunonyland.com](https://qrcode.brunonyland.com)**

## 📦 Biblioteca `qr-gen`

O núcleo da geração de QR Codes desta aplicação é alimentado pela biblioteca **[`@brunonyland/qr-gen`](https://www.npmjs.com/package/@brunonyland/qr-gen)**.

Para mais detalhes sobre como ela funciona, como instalá-la em seus projetos ou para contribuir, acesse o repositório oficial:
🔗 **[Repositório da biblioteca qr-gen no GitHub](https://github.com/brunonyland/qr-gen)** 

## 🛠️ Principais Tecnologias Utilizadas

- **[Angular](https://angular.io/)**: Framework estrutural para a construção da interface.
- **[@brunonyland/qr-gen](https://www.npmjs.com/package/@brunonyland/qr-gen)**: Motor de geração do QR Code.
- **[Three.js](https://threejs.org/) & [GSAP](https://gsap.com/)**: Utilizados para animações e renderização avançada (3D).

## 💻 Como Executar Localmente

Siga os passos abaixo para rodar o projeto no seu ambiente de desenvolvimento:

1. Instale as dependências do projeto:
   ```bash
   npm install
   ```

2. Inicie o servidor de desenvolvimento:
   ```bash
   npm start
   ```

3. Acesse no seu navegador: `http://localhost:4200/`
